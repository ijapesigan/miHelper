# Model Fitting on Imputed Data Sets

Model Fitting on Imputed Data Sets

## Usage

``` r
# S3 method for class 'amelia'
MIFit(x, fit, ...)

# S3 method for class 'data.frame'
MIFit(x, fit, M = 5, fun = "mice", ...)

# S3 method for class 'list'
MIFit(x, fit, ...)

# S3 method for class 'mids'
MIFit(x, fit, ...)

# S3 method for class 'norm'
MIFit(x, fit, ...)

MIFit(x, ...)
```

## Arguments

- x:

  Object.

- fit:

  Object. Output of the model fitting functions (e.g.,
  [`lm()`](https://rdrr.io/r/stats/lm.html),
  [`lavaan::lavaan()`](https://rdrr.io/pkg/lavaan/man/lavaan.html),
  [`lavaan::cfa()`](https://rdrr.io/pkg/lavaan/man/cfa.html),
  [`lavaan::sem()`](https://rdrr.io/pkg/lavaan/man/sem.html)).

- ...:

  Additional arguments for `MIFit.data.frame()` to pass to `fun`. For
  "mcmcNorm": `iter`, the number of data augmentation cycles per
  imputation (default 1000); `prior`, `"noninformative"` (default) or
  `"ridge"`; and `ridge_df`, the degrees of freedom of the ridge prior
  (default 1).

- M:

  Positive integer. Number of imputations for `MIFit.data.frame()`.

- fun:

  Character string. Select function to use for multiple imputation for
  `MIFit.data.frame()`. Valid values include "mice" for
  [`mice::mice()`](https://amices.org/mice/reference/mice.html),
  "amelia" for
  [`Amelia::amelia()`](https://rdrr.io/pkg/Amelia/man/amelia.html), and
  "mcmcNorm" for the multivariate normal model: EM, then data
  augmentation (Schafer, 1997), in C++ in this package.

## Value

Returns an object of class `mifit` which is a list with the following
elements:

- `mi`:

  Multiply imputed data sets.

- `fit`:

  List of models fitted on each imputed data set.

[doi:10.1002/9780470316696](https://doi.org/10.1002/9780470316696)
